## About Me

I'm a **Full-Stack Software Engineer** based in Dublin, Ireland, building business-critical systems — ERP, HR & payroll, finance workflows, and student-management platforms. I work across the stack, from React/TypeScript frontends to Firebase/PostgreSQL backends, with a focus on role-based access control, data import pipelines, and cloud automation.

- 🏢 Currently building **ERP & attendance systems** for education clients (Erin College)
- ☁️ Deep experience with **Firebase**, **Google Workspace APIs**, and **Vercel** deployments
- 🤖 Heavy user of **AI-assisted development** workflows (Claude, Copilot-style agents) for spec-driven builds
- 🌱 Learning: scalable data-loading strategies, cloud deployment optimization, advanced Git workflows
- 💬 Ask me about: Firebase/Firestore architecture, RBAC systems, payroll & finance data pipelines
